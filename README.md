# Life OS

A general-purpose personal information and action system.

## Vision

Life OS is designed to turn information into organized, actionable work:

**Capture → Understand → Organize → Plan → Act → Remember**

The project is intentionally general-purpose rather than tied to a school, business, profession, or regulated industry.

## Current foundation

- Command Center
- Universal Inbox
- Projects
- Tasks
- Notes
- File intake
- AI Workspace foundation
- Data export
- Provider-agnostic architecture

## Planned architecture

1. AI command engine
2. Personal knowledge graph
3. Document intelligence
4. Semantic search
5. Project intelligence
6. AI workflows
7. Human-approved actions
8. Integrations
9. Privacy and data controls
10. PWA/mobile experience

## Development principle

Existing features should remain working when new features are added. Changes should be incremental, testable, and modular.
